How Cardano addresses work

Cardano Shelley enterprise addresses are bech32 strings starting with addr1. After that comes a header character, which for an enterprise mainnet address is always v, then one of y 9 x 8.

Bech32 excludes 1 b i o, so words containing those letters cannot match. The remaining 32 characters are qpzry9x8gf2tvdw0s3jn54khce6mua7l.

Alphabet: Bech32 (32 symbols per position). Typical shape: addr1v…cafe.

How to generate a Cardano vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose Cardano (ada).
  3. Enter a short prefix, suffix, or contains pattern using the Bech32 alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain ada --suffix cafe

Tips for Cardano

  • Words that fit the bech32 set include cafe, dead, fade and defa; anything with b, i, o or 1 (like moon) cannot match.
  • This generates payment-key-only enterprise addresses, not staking-enabled base addresses.
  • Always test with a small amount first.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.

Frequently asked questions

Does the tool create staking addresses?

No — enterprise addresses only (payment key, no stake key).

Which letters are not allowed?

In the data part, 1, b, i and o are not in the bech32 alphabet.
