How Nervos CKB addresses work

Short secp256k1 CKB addresses look like ckb1qyq…. The payload is format 0x01, code hash index 0x00, then blake160 of the compressed public key (Blake2b with personalization ckb-default-hash).

Bech32 excludes 1 b i o in the data part, so choose patterns from the remaining 32 characters.

Alphabet: Bech32 (32 symbols per position). Typical shape: ckb1qyq…cafe.

How to generate a Nervos CKB vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose Nervos CKB (ckb).
  3. Enter a short prefix, suffix, or contains pattern using the Bech32 alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain ckb --suffix cafe

Tips for Nervos CKB

  • The fixed head ckb1qyq is applied for you — put custom characters after it or use a suffix.
  • Short format is widely supported; newer full Bech32m lock-script addresses are out of scope here.
  • Import the hex private key into Neuron or another CKB wallet.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.

Frequently asked questions

Why ckb1qyq?

Short format type 0x01 and secp index 0x00 encode to those leading data characters after the HRP.

Are full CKB addresses supported?

Not yet — this release grinds the popular short secp256k1 form.
