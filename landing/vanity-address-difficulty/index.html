Frequently asked questions

How is vanity address difficulty calculated?

Each position in the pattern must match one specific symbol, so the expected number of attempts is the alphabet size raised to the pattern length.

Why does one extra character make it so much slower?

Every additional character multiplies the expected work by the alphabet size: 16× for hex, 32× for bech32 or Base32, 58× for Base58, 64× for base64.

Does ignoring case make it faster?

Yes for letters, because both upper and lower case forms match. Digits have no case variant, so patterns made of digits do not get faster.

Is the time shown exact?

No. Finding a match is random; the average time is attempts divided by speed, and there is a 63% chance of finishing within that time and about 90% within 2.3× that time.
