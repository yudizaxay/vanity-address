How Zcash addresses work

Zcash transparent P2PKH addresses are Base58Check strings that begin with t1. The network uses a two-byte version prefix, so the leading t1 is fixed and your pattern starts after that.

Shielded Sapling (zs1…) and Unified addresses are out of scope — this mode grinds transparent secp256k1 keys only.

Alphabet: Base58 (58 symbols per position). Typical shape: t1Moon….

How to generate a Zcash vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose Zcash (zec).
  3. Enter a short prefix, suffix, or contains pattern using the Base58 alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain zec --suffix Moon

Tips for Zcash

  • Suffixes such as short words or repeated digits read well on explorers.
  • Import the exported WIF or hex key into a wallet that supports transparent Zcash keys.
  • Case matters in Base58, so Moon and moon are different patterns.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.

Frequently asked questions

Do Zcash addresses always start with t1?

Transparent P2PKH mainnet addresses do. Shielded and Unified formats use other prefixes and are not generated here.

Is a transparent vanity address private?

No. Transparent addresses are visible on-chain like Bitcoin. Use shielded wallets if you need privacy.
