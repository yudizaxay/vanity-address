How Sui addresses work

A Sui address is 0x followed by 64 hex characters, derived by hashing the Ed25519 public key with a signature-scheme flag using Blake2b.

Hex has only 16 symbols per position, so Sui patterns are much cheaper than Base58 ones of the same length. Only 0–9 and a–f are valid.

Alphabet: Hex (16 symbols per position). Typical shape: 0xdead….

How to generate a Sui vanity address

  1. Open the web generator or run npx vanity-address.
  2. Choose Sui (sui).
  3. Enter a short prefix, suffix, or contains pattern using the Hex alphabet.
  4. Check the ETA, grind, then verify the result before using it.
npx vanity-address --chain sui --suffix dead

Tips for Sui

  • Words made from a–f work: dead, cafe, face, fade, decade.
  • Digits can stand in for letters (5 for S, 1 for I) to extend your vocabulary.
  • Export the key and import it into a Sui wallet; the address should match.

Safety

Whoever holds the private key controls the funds. vanity-address creates keys locally from your operating system's secure random source and re-derives every address on the CPU before export. The exported file is a plaintext secret: keep it offline and never commit or email it. Read the security model before moving significant value.
