            01 · chain

            02 · pattern
            
Prefix, suffix, or contains

quick paths

      
Install in one command.

      
Pre-built downloads above, or pick a package manager.


      

        
        
        
        
      


      

        
        
# no install needed — runs instantly
$ npx vanity-address

# or install globally
$ npm install -g vanity-address

      

      

        
        
$ brew tap yudizaxay/tap
$ brew trust yudizaxay/tap
$ brew install vanity-address

      

      

        
        
# requires Rust 1.70+, first compile ~3–8 min
$ cargo install vanity-address

before you stamp

      
Read this before generating keys.

      
A vanity wallet is a real wallet. Treat the private key like cash.

      

        

          
Local only

          
Keys are generated on your machine, never sent anywhere.

        

        

          
No network

          
This tool never connects to the internet while grinding.

        

        

          
Open source

          
Audit the Rust engine trust, but verify.

        

        

          
Verify first

          
Always double-check the address before sending funds.
