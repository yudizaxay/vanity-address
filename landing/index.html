Why vanity-address

Built for speed, privacy, and every chain

One Rust engine, parallel CPU grinding, and zero compromises on where your keys live.

Install

Pick your poison

No Rust or Node.js required for pre-built downloads.

# no install needed — runs instantly
$ npx vanity-address

# or install globally
$ npm install -g vanity-address
$ brew tap yudizaxay/tap
$ brew trust yudizaxay/tap
$ brew install vanity-address
# requires Rust 1.70+, first compile ~3-8 min
$ cargo install vanity-address
# pre-built CLI + desktop .dmg / .exe, no compiler needed
→ github.com/yudizaxay/vanity-address/releases/latest
