Why vanity-address

Built for speed, privacy, and every chain

One Rust engine, parallel CPU grinding, and zero compromises on where your keys live.

Parallel CPU grinding

Rayon-powered multi-core search finds matches in seconds to minutes — with a live keys/sec + ETA readout.

100% local, always

Every keypair is generated on your machine. No network calls, no telemetry, no accounts — ever.

25 chains, one engine

Solana, EVM, Bitcoin, Cosmos, Cardano, TON, and 19 more — same CLI, same desktop app, same trust model.

CLI + Desktop app

Script it with --json, or use the native Tauri wizard with a live progress bar.

Programmatic SDK

npm install vanity-address gives you generateAddress() — runs in-process via WebAssembly.

Prefix, suffix, or both

Exact-case or case-insensitive matching, impractical-pattern warnings, and honest time estimates up front.

Install

Pick your poison

No Rust or Node.js required for pre-built downloads.

# no install needed — runs instantly
$ npx vanity-address

# or install globally
$ npm install -g vanity-address
$ brew tap yudizaxay/tap
$ brew trust yudizaxay/tap
$ brew install vanity-address
# requires Rust 1.70+, first compile ~3-8 min
$ cargo install vanity-address
# pre-built CLI + desktop .dmg / .exe, no compiler needed
