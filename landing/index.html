Browser (no install)

              

                Open vanity-address.online/generate,
                pick Address or Contract, type your word, grind. Keys stay in
                the tab.
              

            

            

              
Name / brand wallet

              

                Use a short prefix or suffix that fits the chain alphabet.
                Longer patterns are exponentially slower the app shows an
                honest ETA first.
              

            

            

              
CLI / desktop

              

                npx vanity-address, Homebrew tap
                yudizaxay/tap, or download from
                GitHub Releases.
              

            

            

              
Contract / mint

              

                Contract mode: EVM CREATE, Tron CREATE, Solana mint, or
                CREATE2. Same local
                privacy model as wallets.
              

            

          

        

      


      
      

        

          

            before you stamp
          

          
Read this before generating keys.

          

            A vanity address is a real keypair. This tool is a generator not a
            wallet and it is not formally audited. Treat the private key like
            cash.
          

          

            

              
Local only

              

                Keys are generated on your machine, never sent anywhere. Saved
                key files are owner-only.
              

            

            

              
No network

              
This tool never connects to the internet while grinding.

            

            

              
Large funds

              

                Prefer offline CLI or desktop on a clean machine. Downloads and
                

                --save are plaintext secrets.
              

            

            

              
Verify first

              

                Always double-check the address before sending funds. Open
                source trust, but verify.
